# 🚀 AI Task Tracker

### Smart Task Management with AI-Powered Priority Suggestions

## Overview

AI Task Tracker is designed to simplify task management by allowing users to create, update, delete, search, and filter tasks. The application also includes an AI-based priority recommendation feature that helps users identify the importance of tasks based on their descriptions.

## ✨ Features

### Task Management

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks

### Search & Filtering

- Search tasks by title
- Filter tasks by status
- Quick task retrieval

### Statistics Dashboard

- Total tasks count
- Completed tasks count
- In-progress tasks count
- To-do tasks count

### AI Integration

- AI-powered priority suggestions
- Priority classification (High, Medium, Low)
- Recommendation explanation
